# Demo systems

Demo versions (fake data, DEMO_MODE) of business systems. Not for production use.

- `demo-sklad/` — CRM + warehouse (Next.js, embedded Postgres)
- `demo-orders/` — order management (Next.js, JSON store)
- `demo-crm/` — CRM PWA (built static + PHP API; create api/config.php from config.example.php)
- `demo-tasks/` — CRM with tasks/deals (PHP + MySQL; see demo-tasks/README.md)
